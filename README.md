# 商品信息自动填写工具

## 图形界面（推荐）

```bash
python autofill/gui.py
```

界面功能一览：
- **采集商品信息**：输入商品详情页链接（需采集账号登录），一键提取所有字段 + 值
- **字段表格**：显示所有字段，**双击【填写值】列**可直接编辑
- **新增字段**：填写字段 ID / 名称 / 类型 / 值 → 点"+ 添加字段"
- **删除字段**：选中行 → 点"删除选中行"
- **保存字段定义**：点"保存字段定义到 fields.py"将新增/删除永久写入文件
- **开始填写**：点"▶ 开始填写"，浏览器自动打开，日志实时输出到界面底部

### 采集功能使用方法

1. 将商品详情页链接粘贴到顶部输入框（如 `https://www.jxemall.com/goods-center/goods/detail?channelItemId=...`）
2. 点【采集并导入字段】→ 自动用采集账号登录 → 打开商品详情页 → 提取所有字段
3. 采集完成后弹窗询问：**替换**（清空现有字段，用采集结果覆盖）或 **合并**（保留现有字段，新增不重复的）
4. 检查字段表内容，确认无误后点【▶ 开始填写】发布

## 文件结构

```
autofill/
  autofill.py   ← 【主入口】修改填写数据、运行此文件
  config.py     ← 账号密码、目标URL、浏览器配置
  fields.py     ← 字段定义表（添加新字段在这里）
  login.py      ← 登录逻辑（一般不需要修改）
  filler.py     ← 填写核心逻辑（一般不需要修改）
```

## 修改填写内容

打开 `autofill/autofill.py`，找到 `FILL_DATA` 部分：

```python
FILL_DATA = {
    "82544":   "盒",       # 计量单位
    "1502406": "格之格",   # 制造商名称
    "1502407": "中",       # 制造商规模
    "82546":   "格之格",   # 生产厂商
}
```

修改对应的值即可。key 是字段 ID（与 `fields.py` 中 `field_id` 一致）。

## 扩展新字段

### 第一步：在 `fields.py` 添加字段定义

```python
FIELD_DEFINITIONS = [
    ...
    {
        "field_id": "你的字段ID",   # 页面中 div.doraemon-select 的 id 属性
        "label": "字段中文名",
        "field_type": "combobox",   # 见下方说明
    },
]
```

**field_type 说明：**
| 类型 | 说明 | 适用场景 |
|------|------|---------|
| `select` | 纯下拉，只能从固定列表选 | 如：计量单位 |
| `combobox` | 可输入下拉，可手动输入或从候选选 | 如：制造商名称、生产厂商 |
| `input` | 普通文本框，直接输入 | 如：电商平台链接 |

### 第二步：在 `autofill.py` 的 FILL_DATA 里加对应值

```python
FILL_DATA = {
    ...
    "你的字段ID": "要填写的值",
}
```

### 如何找字段 ID？
1. 在浏览器中打开商品发布页
2. 按 F12 打开开发者工具
3. 点击"审查元素"，选中对应字段的下拉控件
4. 在 HTML 里找到 `<div class="doraemon-select ..." id="XXXXX">` 的 id 值

## 配置说明（config.py）

```python
HEADLESS = False    # 改为 True 可隐藏浏览器窗口（后台运行）
SLOW_MO = 150       # 操作延迟（毫秒），网速慢时可调大
```

## 常见问题排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 字段未找到 | 页面渲染太慢 | 增大 `config.py` 中 `SLOW_MO`，或在 `autofill.py` 步骤4增加等待时间 |
| 下拉列表无目标选项 | 选项不存在或名称有差异 | 查看日志中"候选列表"，确认实际选项名称 |
| 登录失败 | 密码错误或网络超时 | 检查 `config.py` 中账号密码，增大 timeout |
| 值未保留 | combobox 组件特性，直接输入不触发 blur | 可在 `filler.py` 的 `_fill_combobox` 中添加 `Tab` 键 |
